# mai-react-app 
React + Vite in plain Javascript.

## Steps to create this project
* Install node.js, then execute the following commands:
* "npm create vite@latest"
* "cd [app-project-root]"
* "npm install"
* "npm run dev"
* launch a browser: http://localhost:5173/
